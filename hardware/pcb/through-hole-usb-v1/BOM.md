# through-hole-usb-v1: parts list

Every part for the through-hole-usb-v1 interface board, its cables and its box. The same list is in `through-hole-usb-v1-bom.csv`. Everything is through-hole and hand-soldered.

Generated by `generator/outputs.py` from `generator/design.py`; edit that, not this file, then run `build.sh`. Part numbers were checked against manufacturer datasheets and distributor pages on 2026-11-15. Order codes are Digi-Key UK (stock seen then); Farnell and RS carry most parts too.

## Connector pinouts

**J2, sender harness (Micro-Fit 3.0, 1x4)**

| Pin | Net | Wire to |
|---:|---|---|
| 1 | SENDER | Sender spade terminal (signal) |
| 2 | SENSE | Ground-sense wire to the tank bond stud |
| 3 | GND | Ground return to the tank bond stud (required: the board's ground reference) |
| 4 | GND | Harness screen at this end only, or a second return wire to the same stud |

**J3, display cable (Micro-Fit 3.0, 2x3)**

| Pin | Net | Wire to |
|---:|---|---|
| 1 | GND | Display G (paired with 3.3 V, pin 4) |
| 2 | GND | Display G (paired with SCL, pin 5) |
| 3 | GND | Display G (paired with SDA, pin 6) |
| 4 | +3V3 | Display 3.3V (supplied by the display) |
| 5 | SCL | Display 18 (SCL) |
| 6 | SDA | Display 17 (SDA) |

**Display cable** (J3 to the display's 8-way case socket, left to right seen from the back):

| Case label | Net | J3 pin |
|---|---|---|
| 18 | SCL | 5 |
| 17 | SDA | 6 |
| 16 | - | not connected |
| RX | - | not connected |
| TX | - | not connected |
| 3.3V | +3V3 | 4 |
| G | GND | 1, 2, 3 |
| 5V | - | not connected |

Leave the display's 5V pin unconnected: it carries the display's USB-C supply, and this board doesn't use it.
