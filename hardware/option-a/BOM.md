# Option A: parts list

Every part for option A, whichever way you build it: take the parts every build needs, then the parts for one of the three builds. The CSV files in `veroboard/` and `pcb/` are the same lists for those builds.

Part numbers are given only where they were checked against the maker's data and Digi-Key UK's product page (2026-11-15). Everything else is a specification: any part that meets it will do. Prices and order quantities are deliberately not guessed.

Generated by `scripts/boards/outputs.py` from `scripts/boards/circuit.py`: edit those, not this file, then run `scripts/boards/build.sh`.
